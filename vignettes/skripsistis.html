Paket skripsistis menyediakan kerangka (template) proyek Quarto untuk penyusunan skripsi yang dikhususkan bagi mahasiswa Program Studi D-IV Komputasi Statistik, Politeknik Statistika STIS, sesuai Pedoman Skripsi KS Edisi Keenam (2025). Template ini tidak ditujukan untuk program studi lain. Panduan ini membahas penggunaan paket secara menyeluruh: mulai dari membuat proyek, mengisi metadata, menulis isi (kutipan, tabel, gambar, persamaan, definisi/teorema, algoritma, dan kode-sebagai-gambar), hingga merender ke PDF.

⚠️ Status: versi pengembangan (tidak resmi). Paket ini masih dalam tahap pengembangan dan belum sepenuhnya mengikuti panduan penulisan skripsi Politeknik Statistika STIS. Format dan ketentuan yang dihasilkan dapat berubah serta perlu diperiksa kembali terhadap pedoman resmi sebelum digunakan untuk pengajuan; ini bukan templat resmi STIS. Versi stabil akan dirilis setelah seluruh ketentuan sesuai dengan panduan.

Prasyarat

Sebelum memakai paket ini, pastikan perangkat berikut tersedia:

  • R beserta paket knitr, rmarkdown, dan tikzDevice;
  • Quarto versi 1.4 atau lebih baru (https://quarto.org/docs/get-started/);
  • distribusi LaTeX dengan XeLaTeX beserta paket algorithm2e. Cara termudah adalah memasang TinyTeX melalui Quarto:
# di terminal
quarto install tinytex

Paket LaTeX yang belum ada (mis. algorithm2e, lmodern) akan dipasang otomatis oleh Quarto/TinyTeX saat render pertama.

Instalasi

# dari berkas sumber (.tar.gz)
install.packages("skripsistis_0.2.1.tar.gz", repos = NULL, type = "source")

# atau dari GitHub
# remotes::install_github("madsyair/skripsistis")

Membuat proyek skripsi

Fungsi utama paket ini adalah buat_skripsi(). Fungsi tersebut menyalin seluruh kerangka proyek ke direktori baru dan mengisi metadata (judul, nama, NIM, pembimbing, penguji, dan lain-lain) secara otomatis.

Lewat menu RStudio

Selain dari konsol, template tersedia di RStudio melalui File → New Project… → New Directory → Skripsi Komputasi Statistik (Politeknik Statistika STIS). Dialog menanyakan judul, nama, NIM, peminatan, dan pembimbing.

Perlu dicatat: dialog File → New File → Quarto Document di RStudio tidak dapat memuat template dari paket R (hanya membuat satu .qmd kosong). Karena skripsi ini berupa proyek multi-berkas, gunakan Templat Proyek di atas atau fungsi buat_skripsi().

Peminatan dan kerangka bab

Argumen peminatan menentukan kerangka bab:

  • Sains Data — Bab I Pendahuluan, II Tinjauan Pustaka, III Metode Penelitian, IV Hasil dan Pembahasan, V Kesimpulan dan Saran.
  • Sistem Informasi Statistik — Bab I–III sama, lalu IV Analisis dan Perancangan, V Implementasi dan Evaluasi, VI Kesimpulan dan Saran.

Berkas bab yang tidak relevan dengan peminatan terpilih otomatis dihapus, dan daftar include pada index.qmd disusun sesuai kerangka tersebut.

Daftar argumen

Argumen Keterangan

Contoh

library(skripsistis)

buat_skripsi(
  path        = "skripsi-saya",
  judul       = "Pemodelan Proxy Means Test Berbasis GPBoost di Provinsi Jawa Timur",
  nama        = "Nama Mahasiswa",
  nim         = "222212501",
  peminatan   = "Sains Data",
  ketua_prodi = "Nama Ketua Program Studi",
  pembimbing  = "Nama Pembimbing",
  render      = FALSE   # set TRUE untuk langsung membuat PDF
)

Cuplikan berikut menjalankan buat_skripsi() ke direktori sementara dan menampilkan struktur proyek yang dihasilkan:

Penjelasan singkat tiap berkas:

  • _quarto.yml — pusat konfigurasi (format PDF, gaya sitasi, bibliografi, awalan rujukan silang berbahasa Indonesia).
  • index.qmd — Prakata, Abstrak, penyisipan Daftar Isi/Tabel/Gambar, pemanggilan tiap bab, Daftar Pustaka, dan Lampiran.
  • bab/ — berkas tiap bab (bab1_pendahuluan.qmd … bab5_kesimpulan.qmd, lampiran.qmd).
  • tex/preamble.tex — pengaturan format (margin 4-3-3-3 cm, font Times, spasi 1,5, judul bab, algoritma).
  • tex/00_frontmatter.tex — halaman muka (sampul s.d. lembar hak cipta).
  • referensi.bib — basis data referensi (BibTeX).
  • apa-stis-id.csl — gaya sitasi APA 7 modifikasi bahasa Indonesia.
  • img/ — berisi logo_stis.png (logo bawaan sudah disertakan; boleh diganti).

Merender ke PDF

Setelah proyek dibuat, render dengan salah satu cara berikut:

# dari R
skripsistis::render_skripsi("skripsi-saya")

# atau langsung dari terminal
# quarto render skripsi-saya

Hasil PDF berada di subfolder _output/.

Mengganti logo dan metadata

  • Logo: logo_stis.png sudah disertakan di folder img/ (boleh diganti). Jika tidak ada, halaman sampul tetap dirender dengan ruang logo dikosongkan.
  • Metadata: nilai yang diisi lewat buat_skripsi() sudah tertanam pada _quarto.yml dan berkas .tex. Untuk mengubahnya kemudian, sunting langsung berkas-berkas tersebut.

Menulis isi skripsi

Kutipan dan daftar pustaka

Gaya sitasi mengikuti APA edisi ke-7 dengan modifikasi bahasa Indonesia (penghubung “dan”, tiga penulis atau lebih disingkat “dkk.”, tanpa tahun “t.t.”, “ed. ke-2”, “Penerj.”). Tambahkan entri ke referensi.bib, lalu rujuk pada naskah:

Penulisan Hasil
[@kunci2025] (Nama dkk., 2025)
@kunci2025 Nama dkk. (2025)
[@a2020; @b2021] (A dkk., 2020; B dkk., 2021)

Daftar Pustaka tersusun otomatis, hanya memuat referensi yang dikutip, dan terurut alfabetis.

Definisi, teorema, dan bukti

Tersedia lingkungan matematika bernomor dan dapat dirujuk: Definisi (#def-), Teorema (#thm-), Lema (#lem-), Akibat (#cor-), Proposisi (#prp-), Contoh (#exm-), serta lingkungan Bukti (.proof).

::: {#def-pmt}
**(Proxy Means Test).** Misalkan $y_i$ menyatakan log pengeluaran per kapita ... .
:::

::: {#thm-takbias}
Penduga kuadrat terkecil $\hat{\boldsymbol{\beta}}$ bersifat takbias.
:::

::: {.proof}
Bukti mengikuti definisi. $\qed$
:::

Lihat @def-pmt dan @thm-takbias.

Algoritma

Algoritma ditulis dengan algorithm2e (kata kunci telah dilokalkan ke bahasa Indonesia: Masukan, Keluaran, untuk, selama, kembalikan) dan bernomor deret tunggal.

```{=latex}
\begin{algorithm}[H]
\caption{Estimasi PMT}\label{alg-pmt}
\KwIn{Data $\mathbf{X}$, target $y$}
\KwOut{Model $\hat{f}$}
\ForEach{kandidat $m$}{ Latih $m$\; }
\Return $\hat{f}$\;
\end{algorithm}
```

Rujuk dengan Algoritme \ref{alg-pmt}.

Memakai gaya sitasi pada dokumen lain

Berkas CSL APA 7 modifikasi Indonesia dapat dipakai pada dokumen Quarto/R Markdown lain. Lokasinya:

skripsistis::path_csl()
#> [1] "/home/madsyair/Documents/project/R Package/skripsistis/inst/csl/apa-stis-id.csl"

Pada YAML dokumen lain, cukup tambahkan csl: path/ke/apa-stis-id.csl dan lang: id.

Pemecahan masalah

  • quarto tidak ditemukan — pasang Quarto dan pastikan ada pada PATH.
  • rmarkdown/knitr tidak tersedia — install.packages(c("rmarkdown", "knitr")).
  • Gambar tikz gagal — pastikan tikzDevice terpasang dan XeLaTeX tersedia; untuk satu gambar bermasalah, gunakan opsi chunk #| dev: ragg_png.
  • Paket LaTeX hilang (mis. algorithm2e) — biarkan TinyTeX memasang otomatis, atau jalankan quarto install tinytex.

Penutup

Dengan paket ini, seluruh laporan dapat dirender satu kali (quarto render) dan mesin LaTeX di balik layar menyusunnya dengan format yang konsisten: halaman muka STIS, penomoran Romawi/Arab, gaya sitasi APA 7 Indonesia, serta penyajian tabel, gambar, persamaan, definisi/teorema, algoritma, dan kode-sebagai-gambar.

Daftar Singkatan dan Lambang (opsional)

Elemen ini nonaktif secara bawaan (Pedoman KS 2025 tidak mewajibkannya). Aktifkan dengan daftar_singkatan = TRUE; isinya dibaca dari singkatan.csv (live-computed) atau diisi lewat argumen singkatan (vektor bernama / data.frame 2 kolom / matriks 2 kolom). Elemen muncul setelah Daftar Lampiran dengan gaya dan penomoran halaman Romawi yang seragam.

buat_skripsi(path = "skripsi-saya", daftar_singkatan = TRUE,
             singkatan = c("BPS" = "Badan Pusat Statistik",
                           "$\\mu$" = "rata-rata populasi"))
